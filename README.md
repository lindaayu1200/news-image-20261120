# THE WORLD WIRE — Friday 20 November 2026

One 1024x1024 image summing up the world's news of **Friday 20 November
2026**: a flat-vector newspaper front page — navy masthead, three lead
stories (Russia's giant overnight barrage on Ukraine, the first
Trump–Xi–Putin trilateral, Cyclone Akvan's landfall in India), a six-card
illustrated grid (ICJ's Myanmar genocide ruling, GTA VI's record launch,
Anthropic's near-$2tn debut, COP31's fossil-fuel-free draft, a tanker fire
in the Strait of Hormuz, Houthi missiles at Riyadh), a dotted world map
with 17 numbered red pins and a continent legend, and 26 numbered "also on
Friday" briefs — 35 date-checked stories across six continents, with
sources in the footer.

## How it works

`main.py` (Python 3.13, standard library only) writes `entry.png` to the
directory named by the `MAKEFUN_OUTPUT_DIR` environment variable
(default `/output`):

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
