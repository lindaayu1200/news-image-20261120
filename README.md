# 20 Nov 2026 world news mosaic

One image summing up the world's news of Friday 20 November 2026 — an
eight-tile mosaic: Russia's overnight barrage on Ukraine, the Trump–Xi–Putin
Shenzhen summit, the ICJ's first-ever state genocide ruling against Myanmar,
the Houthi strike on a Riyadh tower, Türkiye's Kizilelma drone fighter
entering service, South Korea's exports topping $1 trillion, Kenya's marathon
champion Peres Jepchirchir banned for doping, and the GTA VI global launch.

## How it works

`main.py` (Python 3.13, standard library only) writes `entry.png` to the
directory named by the `MAKEFUN_OUTPUT_DIR` environment variable
(default `/output`):

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
